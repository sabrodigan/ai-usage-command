# ai-usage-command

Source for the **`usage`** CLI, which monitors AI model and token usage across coding
agents and providers — Claude, Codex, Gemini, Copilot, Cursor (per model, e.g. Grok),
Meta Muse, Antigravity, Warp, Ollama and OpenAI-compatible endpoints.

- Documentation: [`ai-usage/README.md`](ai-usage/README.md)
- Binaries for Linux, macOS and Windows: [Releases](https://github.com/sabrodigan/ai-usage-command/releases)
- Omarchy bar widget: [sabrodigan/omarchy-ai-usage](https://github.com/sabrodigan/omarchy-ai-usage)
